# Drop Tracker
**proyectobasuravibecodeado**

## Requisitos
- Node.js
- npm
- Git

## Como ejecutarlo (sin descargar la versión compilada pues)

### 1. Clonar el repositorio

```bash
git clone https://github.com/J0shUnk09/drop-tracker
```

### 2. Entrar en la carpeta del proyecto

```bash
cd drop-tracker
```

### 3. Instalar dependencias

```bash
npm install
```

### 4. Ejecutar el servidor

```bash
npm run dev
```
En la terminal se muestra el localhost

### 5. Compilar para producción

```bash
npm run build
```

Para comprobar localmente la versión compilada:

```bash
npm run preview
```
